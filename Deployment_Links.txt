3. Local Setup Instructions (Zero-Dependency Evaluation Fallback):
------------------------------------------------------------------
In case cloud services are temporarily unavailable or for in-depth code inspection:

Step 1: Start the Backend REST API
  cd backend
  npm install
  npm run dev
  -> Runs on http://localhost:5000
  -> Automatically detects local or cloud MongoDB; seamlessly spins up an
     in-memory MongoDB instance with realistic seed data if MongoDB is absent!

Step 2: Start the React Frontend Application
  cd frontend
  npm install
  npm run dev
  -> Runs on http://localhost:5173

Step 3: Access Local Application
  - Candidate Portal:    http://localhost:5173/
  - Admin Login:         http://localhost:5173/admin/login
  - Admin Dashboard:     http://localhost:5173/admin/dashboard
  - Backend API Health:  http://localhost:5000/api/health
